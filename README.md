 Company Analysis:

Excel-based financial analysis of Indian listed companies, built as part of my journey to become a financial analyst.

Data source: Screener.in (consolidated, ₹ crore). All ratios are calculated with Excel formulas linked to the source data.

 Asian Paints #1 : (Mar-24 to Mar-26)

File: [Asian Paints Analysis.xlsx](Asian%20Paints%20Analysis.xlsx)

 Summary:

Asian Paints is a low-debt, profitable company. FY Mar-25 was weak: sales fell 4.48% and net profit fell 32.84%. Mar-26 shows recovery, but profit is still below Mar-24.

Scope:

This is my first company analysis. It covers ratio analysis (profitability, returns, leverage and efficiency). Later analyses will add cash flow, peer comparison and DCF valuation.

 Key Numbers (₹ crore)

| Metric | Mar-24 | Mar-25 | Mar-26 |
| Sales | 35,494.73 | 33,905.62 | 35,583.54 |
| Operating Profit | 7,584.98 | 6,006.21 | 6,699.73 |
| Net Profit | 5,460.23 | 3,667.23 | 4,325.35 |

 Ratio Analysis:

| Ratio | Mar-24 | Mar-25 | Mar-26 |

| Operating Margin | 21.37% | 17.71% | 18.83% |
| Net Profit Margin | 15.38% | 10.82% | 12.16% |
| Sales Growth | - | -4.48% | 4.95% |
| Net Profit Growth | - | -32.84% | 17.95% |
| Return on Equity | 29.15% | 18.90% | 20.24% |
| Return on Assets | 18.26% | 12.08% | 12.53% |
| Asset Turnover | 1.19 | 1.12 | 1.03 |
| Interest Coverage | 36.97 | 26.46 | 34.29 |
| Debt-to-Equity | 0.13 | 0.12 | 0.18 |

 Key Findings:

1. Profitability: Margins fell in Mar-25 and recovered in Mar-26, but have not reached Mar-24 levels.
2. Debt: Debt-to-equity is low, but borrowings rose from ₹2,290 crore to ₹3,929 crore in Mar-26.
3. Debt safety: Interest coverage is above 26x in every year, so profit easily covers interest.
4. Returns: ROE fell from 29.15% to 18.90%, then recovered to 20.24%.
5. Efficiency: Asset turnover keeps falling (1.19 to 1.03), so assets are growing faster than sales.

 Method:

1. Export 10 years of data from Screener.in
2. Link the numbers into an Analysis sheet
3. Calculate margins, growth, return and leverage ratios
4. Write findings in simple language
